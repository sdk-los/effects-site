# ParticleFlow

Интерактивная полноэкранная система частиц с панелью настроек, пресетами и поддержкой PWA.

## Возможности

- **Полноэкранный canvas** с анимированными частицами и сглаживанием под Retina-дисплеи;
- **4 пресета настроек**: Calm, Neon, Storm, Minimal — быстрое переключение между сценариями;
- **6 цветовых палитр**: монохромная, холодная, тёплая, неоновая, радужная и пользовательская (3 кастомных цвета);
- **4 режима курсора**: притяжение, отталкивание, орбита и след;
- **3 режима фона**: сплошной, градиент, прозрачный;
- **15 форм частиц**: круг, квадрат, треугольник, ромб, звезда, капля, многоугольник, крест, кольцо, сердце, стрелка, полумесяц, молния, спираль, бесконечность;
- **13 режимов само-дрейфа**: случайный, горизонтальный, вертикальный, направленный, орбитальный (индивидуальный и общий), волновой, спиральный и другие;
- **Взрывы по клику**: два режима — вспышка (burst) и рождение (spawn), с настройками количества, скорости, времени жизни и размера частиц;
- **Тропы частиц**: затухающие следы за частицами с регулировкой длины, прозрачности и цвета;
- **Соединения между частицами**: линии между ближайшими частицами с пространственной оптимизацией;
- **Северное сияние (Aurora)**: анимированный эффект цветных полос с режимом наложения screen;
- **Пульсация размера** частиц и **отражение от границ** экрана;
- **Свечение** (ShadowBlur) с регулировкой интенсивности;
- **HUD-индикаторы**: FPS и количество частиц на экране;
- **Блокировка ориентации** экрана (portrait) на мобильных устройствах;
- **Автоматическое разрешение конфликтов** между эффектами (trail ↔ shadowBlur);
- **Профили производительности**: без ограничений, экономный, сбалансированный и максимальный, с отдельными безопасными лимитами для мобильных устройств;
- **Адаптивное качество**: автоматическое снижение тяжёлых настроек при устойчивом падении FPS с приоритетом последнего изменённого параметра;
- **Сохранение настроек** в `localStorage` — параметры восстанавливаются после перезагрузки;
- **Ссылки на сцены** — генерация URL с закодированными настройками для быстрого обмена и восстановления конфигурации;
- **PWA**: Service Worker для офлайн-работы, манифест для установки на устройство, иконки для iOS и Android.

### Профили производительности

Профиль задаёт верхние границы для количества частиц, DPR canvas, дальности и
прозрачности соединений, длины троп и свечения. При смене профиля значения,
которые превышают его лимит, автоматически уменьшаются и сохраняются.

| Профиль | Количество частиц (desktop / mobile) | DPR (desktop / mobile) |
|---|---:|---:|
| Без ограничений | 5000 / 5000 | без лимита / без лимита |
| Экономный | 120 / 80 | 1 / 1 |
| Сбалансированный | 500 / 250 | 1.5 / 1.25 |
| Максимальный | 1500 / 750 | 2 / 1.5 |

### Адаптивное качество

Адаптивное качество включается в разделе «Производительность» и работает поверх
текущей конфигурации. Если FPS ниже 30 на трёх последовательных замерах,
система снижает нагрузку и ждёт 1500 мс перед следующим снижением. Параметр
выбирается в следующем порядке:

1. `showConnections`;
2. `auroraEnabled`;
3. `particleCount` — уменьшается примерно на 25%, но не ниже 80;
4. `shadowBlur` — уменьшается на 10, но не ниже 0;
5. `trailLength` — уменьшается на 4, но не ниже 4.

При включённой настройке «Сначала уменьшать последнюю изменённую настройку»
сначала выбирается последний вручную изменённый тяжёлый параметр, если его ещё
можно уменьшить. Автоматическое снижение сразу записывается в пользовательскую
конфигурацию и сохраняется в `localStorage`, поэтому после перезагрузки оно
остаётся активным. Постепенного автоматического восстановления после улучшения
FPS нет: пользователь может вернуть значения вручную.

Адаптивное качество отличается от профиля производительности. Профиль задаёт
постоянные верхние лимиты для сцены и устройства, а адаптивный режим реагирует
на фактический FPS во время работы и последовательно уменьшает только доступные
тяжёлые параметры.

## Пресеты настроек

| Пресет | Описание |
|--------|----------|
| **Calm** | Спокойные холодные тона, низкая скорость частиц, мягкое притяжение к курсору, лёгкое свечение. |
| **Neon** | Яркие неоновые цвета, высокая скорость, орбитальное движение вокруг курсора, интенсивное свечение, северное сияние. |
| **Storm** | Хаотичное отталкивание от курсора, радужная палитра, высокая скорость, тёмный фон, само-дрейф. |
| **Minimal** | Минималистичный режим: прозрачный фон, мало частиц, след курсора, без свечения, пульсации и отражений. |
| **Constellation** | Холодные кольца складываются в живые созвездия: локальные орбиты, пульсация, реакция на курсор и тонкие соединения без свечения и следов. |
| **Comet** | Быстрые капли с длинными следами; число частиц ограничено, а свечение, соединения и aurora выключены. |
| **Aurora** | Волнообразные неоновые частицы на фоне северного сияния; aurora создаёт свет сама, поэтому дорогие свечение, следы и соединения выключены. |
| **Fireworks** | Звёзды с тёплой пользовательской палитрой: каждый клик добавляет постоянную спиральную вспышку. |

Новые пресеты применяют полную конфигурацию, поэтому после переключения не остаются случайно включённые тяжёлые эффекты. Следы и свечение не используются вместе; режимы с соединениями, aurora или вспышками ограничивают число частиц.

## Ссылки на сцены

Функция «Ссылки на сцены» позволяет делиться текущей конфигурацией частиц через URL. При открытии такой ссылки все настройки автоматически восстанавливаются.

### Как это работает

1. **Генерация ссылки**: кнопка «Скопировать ссылку на сцену» в настройках вызывает функцию, которая:
   - Собирает все текущие настройки в JSON-объект
   - Кодирует его в base64 (URL-safe)
   - Добавляет к текущему URL как hash: `#scene=<encoded_data>`

2. **Копирование**: ссылка автоматически копируется в буфер обмена через Clipboard API

3. **Восстановление**: при загрузке страницы скрипт проверяет наличие hash-параметра `#scene=` и:
   - Декодирует base64 обратно в JSON
   - Применяет все сохранённые настройки
   - Обновляет UI контролы в соответствии с загруженными значениями

### Формат ссылки

```
https://yourdomain.com/#scene=eyJjb3VudCI6MTAwLCJzcGVlZCI6MS41LCJjb2xvciI6IiMwMGZmMDAiLC...
```

> **Примечание:** Ссылка содержит только параметры настроек, без состояния анимации (позиции частиц, FPS и т.д.).

## PWA (Progressive Web App)

Проект является полноценным PWA и поддерживает установку на устройство:

- **Service Worker** ([`sw.js`](sw.js)) регистрируется при загрузке страницы и кэширует все статические файлы при первой установке;
- **Обновления**: GitHub Actions добавляет SHA коммита в имя кэша. При следующем открытии или возврате в приложение PWA проверяет обновление, загружает полный новый офлайн-кэш и один раз перезапускается;
- **Стратегия кэширования**: Cache-First для статических файлов, а навигация сначала обращается к сети и при отсутствии сети использует кэшированный `index.html`;
- **Манифест** ([`manifest.json`](manifest.json)) содержит метаданные для установки приложения на домашний экран;
- **Поддержка платформ**: Android (Chrome), iOS (Safari), Windows (Edge/IE);
- **Офлайн-режим**: после первого открытия приложение полностью работает без интернета;
- **Блокировка ориентации**: принудительная portrait-ориентация на мобильных устройствах через `screen.orientation.lock()`.

## Формы частиц

Частицы могут принимать одну из 15 геометрических форм. Форма применяется как к основным частицам, так и к частицам взрывов.

| Форма | Описание |
|-------|----------|
| `circle` | Круг (по умолчанию) |
| `square` | Квадрат |
| `triangle` | Треугольник |
| `diamond` | Ромб |
| `star` | Пятиконечная звезда |
| `drop` | Капля |
| `polygon` | Правильный шестиугольник |
| `cross` | Крест |
| `ring` | Кольцо (рисуется stroke, не fill) |
| `heart` | Сердце |
| `arrow` | Стрелка вверх |
| `crescent` | Полумесяц |
| `bolt` | Молния |
| `spiral` | Спираль (рисуется stroke) |
| `infinity` | Символ бесконечности (рисуется stroke) |

## Само-дрейф (Self-Drift)

Режим автономного движения частиц без участия курсора. Включается тумблером «Само-дрейф» в разделе «Движение».

### Параметры

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| `selfDriftIntensity` | Сила дрейфа | 0.0 – 1.0 |
| `selfDriftSpeed` | Скорость дрейфа | 0.1 – 3.0 |
| `selfDriftMode` | Режим движения | 17 режимов (см. ниже) |
| `selfDriftDirection` | Направление (для режима `directional`) | 0° – 360° |
| `selfDriftOrbitRadius` | Радиус орбиты (для `orbit` / `orbitGlobal`) | 0% – 100% |

### Режимы дрейфа

| Режим | Описание |
|-------|----------|
| `random` | Случайное блуждание (по умолчанию) |
| `leftRight` | Горизонтальное качание влево-вправо |
| `upDown` | Вертикальное качание вверх-вниз |
| `up` | Только вверх |
| `down` | Только вниз |
| `left` | Только влево |
| `right` | Только вправо |
| `directional` | Движение под фиксированным углом (настраивается) |
| `orbit` | Орбита вокруг индивидуальной точки привязки |
| `orbitGlobal` | Орбита вокруг общего центра экрана |
| `wave` | Волновое движение (фаза зависит от позиции частицы) |
| `flow` | Поток: частицы следуют плавному полю течений |
| `lissajous` | Локальные траектории в форме восьмёрок |
| `vortex` | Пульсирующий вихрь вокруг центра экрана |
| `spiral` | Спиральное движение с пульсирующим радиусом |

## Взрывы по клику

При клике или касании экрана в точке взаимодействия создаётся взрыв частиц. Управляется из раздела «Взрывы» панели настроек.

### Параметры

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| `explosionEnabled` | Включение/выключение взрывов | вкл/выкл |
| `explosionMode` | Режим: `burst` (вспышка — исчезают) или `spawn` (рождение — остаются) | burst / spawn |
| `explosionCount` | Количество частиц во взрыве | 5 – 1000 |
| `explosionSpeed` | Скорость разлёта частиц | 1 – 20 |
| `explosionLifetime` | Время жизни частиц (мс) | 200 – 3000 |
| `explosionSize` | Размер частиц взрыва | 1 – 15 |

Параметры «Время жизни» и «Размер частиц взрыва» доступны только для режима `burst`:
в режиме `spawn` частицы остаются в системе и используют общий размер частиц.

### Режимы взрыва

- **Burst** — частицы взрыва создаются как временные объекты `ExplosionParticle`, затухают и исчезают.
- **Spawn** — частицы взрыва создаются как полноценные `Particle` и остаются в системе, увеличивая общее количество частиц.

## Тропы частиц (Trails)

Затухающие следы, которые частицы оставляют за собой при движении. Управляется из раздела «Тропы частиц».

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| `trailEnabled` | Включение/выключение троп | вкл/выкл |
| `trailLength` | Длина следа (количество точек) | 2 – 30 |
| `trailOpacity` | Прозрачность следа | 0.05 – 1.0 |
| `trailColor` | Цвет следа | HEX (`#RRGGBB`) |

> **Важно:** Тропы и свечение (ShadowBlur) конфликтуют по производительности. При включении троп свечение автоматически отключается, и наоборот.

## Соединения между частицами

Линии, соединяющие ближайшие частицы. Управляется из раздела «Соединения».

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| `showConnections` | Включение/выключение соединений | вкл/выкл |
| `connectionDistance` | Максимальная дистанция для соединения | 30 – 300 |
| `connectionWidth` | Толщина линии | 0.2 – 5.0 |
| `connectionOpacity` | Прозрачность линий | 0.0 – 1.0 |

Для оптимизации используется **пространственная сетка (spatial grid)**: канвас разбивается на ячейки размером `connectionDistance`, и соединения проверяются только между частицами в соседних ячейках. Это снижает сложность с O(n²) до O(n).

## Северное сияние (Aurora)

Анимированный эффект цветных полос, накладываемых поверх фона в режиме `screen`. Управляется из раздела «Фон».

| Параметр | Описание | Диапазон |
|----------|----------|----------|
| `auroraEnabled` | Включение/выключение эффекта | вкл/выкл |
| `auroraIntensity` | Интенсивность свечения полос | 0.0 – 1.0 |
| `auroraSpeed` | Скорость анимации | 0.1 – 2.0 |

Эффект использует 6 цветных полос с плавно меняющимися оттенками (hue) на основе текущего базового оттенка частиц.

## Тестирование

В проекте есть автоматические тесты PWA-конфигурации. Для запуска:

```bash
node tests/pwa-config.test.js
```

Тесты проверяют:
- Корректность манифеста (name, start_url, display, icons);
- Наличие PWA-метаданных в `index.html`;
- Стратегию кэширования Service Worker.

## Развёртывание

Проект разворачивается на **GitHub Pages**. Перед публикацией workflow создаёт каталог `_site` и подставляет SHA коммита в `sw.js`: это гарантирует отдельный кэш для каждого успешного деплоя. Для корректной работы PWA на подпути (subpath) используются относительные пути (`./`) в манифесте и Service Worker. Файл `.nojekyll` отключает обработку Jekyll, что необходимо для сохранения статических ассетов.
